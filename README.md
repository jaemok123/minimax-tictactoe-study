# minimax-tictactoe-study
minimax란? 두명이 번갈아 두는 게임에서, 상대와 내가 최선을 둔다 가정했을 때 유리한 수를 고르는 알고리즘
MAX: 내 차례에 가장 점수가 큰 수 선택
MIN: 상대 차례에 가장 점수가 낮은 수 선택
게임 트리: 게임에서 가능한 모든 진행 경과를 나무 모양으로 펼친 구조 리프 노드에는 승, 패, 무승부가 있음.
1단계: 현재 상태에서 시작해 가능한 수를 전부 두며 트리를 끝까지 내려간다.
2단계: 게임이 끝난 상태(리프)에서 점수를 부여한다 (승+, 패-, 무 0)
3단계: 리프 바로 위 층부터 규칙을 적용한다.
4단계: 한 층씩 올라가며 반복한다.
5단계: 루트에 도달하면 자식 중 최고점을 가진 수를 선택한다.
자식 노드의 점수가 반환값으로 부모에게 전달되고, 부모가 그 값들로 자기 점수를 계산한다.
즉 미니맥스는 가장 최악의 상황에서 최선의 수를 고르는 방식이다.
깊이 우선 탐색(DFS): 한 가지를 끝까지 내려간 뒤 되돌아와 다음 가지 탐색
